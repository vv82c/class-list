# 课堂归档

> **上课不用记笔记，认真听课就好。**
> 拍下来的 PPT 和板书，课后拖进应用：自动裁剪、增强，并按课表归到对应的课程和"第几堂"。

在线使用：**https://vv82c.github.io/class-list/**（桌面网页应用，Chrome/Edge 使用并固定用一个；支持离线打开）

## 它解决什么问题

一天四五节课，拍了一堆照片，晚上想复习时问题就来了：这张是哪门课的？上周那次课讲的啥？老师说"要考"的那页在哪？

把照片按"哪门课、第几堂"整理好，是一件繁琐但适合交给程序的事；而课堂上听懂知识这件事，没法交给任何程序。这个工具把前者接管下来，把你的时间留给后者。

## 和课表应用的区别

课表应用回答"**什么时候上什么课**"；课堂归档回答"**拍下来的课堂内容在哪、是哪一堂的**"。

一个管上课时间，一个管上课内容——互补，不重叠。所以它们不冲突：课表继续用，拍下来的内容交给这里。

## 使用流程（如实描述）

1. **课前**：录入课表（支持单周/双周/前八周/后八周/自定义周次），设置学期第一周
2. **课上**：拍下 PPT 和板书，收手机，认真听课
3. **课后**：用数据线 / LocalSend / 微信"文件"把照片拷到电脑，拖进应用——应用自动完成剩下的事：检测边缘、透视校正、画质增强，并按 EXIF 拍摄时间归到课程和"第几堂"（±10 分钟容差，含单双周判断）

**明确说明：本应用不做任何自动同步。** 手机和电脑之间没有魔法——照片需要你亲手拷一次、亲手拖一次，这两下是手动 的；拷完之后的所有整理（裁剪、增强、归课、编号）是全自动的。数据也永远只存在你电脑的浏览器里，不上传任何服务器。

## 功能一览

- **自动归档**：拍摄时间 × 课表时间槽 × 单双周/周次范围，拖进来就归位；课表改了点「重新归课」批量重算，手动改过的照片永不覆盖
- **课堂时间线**：每门课按「第几堂」编号回顾（第 1 堂到第 N 堂，跨时间槽连续编号），并记住你上次看到哪里
- **大屏复习**：滚轮缩放、拖动平移、连播；按课程/周次/标星过滤
- **图片增强**：自动透视校正 + 去投影偏色 + 锐化，斜拍的投影照片变成端正清晰的"文档"
- **标注**：荧光笔（透字）、碳素笔、文字框，支持撤销和橡皮；一键导出带标注的图片
- **重点标星**：老师说"要考"的那页标个星，期末按课程 + 标星过滤，就是复习清单
- **隐私优先**：无账号、无服务器、无埋点。数据只存在你电脑的浏览器沙箱里

## 数据安全（务必阅读）

数据存储在**浏览器私有沙箱**（OPFS + IndexedDB）中，云端没有任何副本；清除浏览器站点数据或重装系统 = 数据丢失。请养成习惯：**每月在「备份」页导出一次完整备份包**，存到网盘或移动硬盘——它是唯一的恢复手段。

## 明确不做的

自动同步与云备份（无服务器架构，zip 导出是唯一且足够的迁移方式）、OCR 转文字笔记、账号系统、iOS/HEIC。

## 技术栈与质量

- Vite + React 18 + TypeScript + Tailwind CSS v4，react-router（HashRouter）
- 存储：OPFS（图片文件）+ IndexedDB（元数据，idb，schema v3）
- 图像：OpenCV WASM（边缘检测与透视校正，懒加载）+ 纯 JS 自动增强管线 + SVG 矢量标注层
- PWA：Service Worker 离线缓存（应用壳）
- 测试：43 个 lib 层单测（`npm test`），覆盖 EXIF 解析、课表匹配与单双周、堂数推导、透视校正、图像增强、标注几何

## 本地开发

```bash
npm install
npm run dev        # 启动开发服务器
npm test           # 43 个 lib 层单测
npm run typecheck  # tsc --noEmit
npm run build      # 类型检查 + 构建 + 生成 Service Worker
npx gh-pages -d dist  # 发布到 GitHub Pages
```
