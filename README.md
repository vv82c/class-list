# 课堂归档

> **上课解放双手：不用记笔记，认真听课。**
> 知识点的整理、作业要用的资料，留到课后在电脑大屏上完成。

在线使用：**https://vv82c.github.io/class-list/**（PWA，可添加到主屏幕、支持离线）

## 和其他课表应用的本质区别

市面上的课表 App 解决的是"**什么时候上什么课**"——但下课铃一响，它们帮不了你任何事。

课堂归档管的是后半段：**课堂内容本身**。

| | 课表 App | 课堂归档 |
|---|---|---|
| 上课铃响时 | 提醒你去上课 | 提醒你：掏出手机拍两张，然后**专心听课** |
| 课堂上的动作 | 看一眼课表 | 拍照，10 秒，不用抄板书、不用录音回放、不用记任何东西 |
| 下课后 | 没有然后 | 电脑打开，照片已经自动躺在对应的课程和"第几堂"下面 |
| 复习时 | 无 | 大屏按课程/第几堂/周次/标星检索，缩放看 PPT 小字，荧光笔标重点 |

一句话：**课表管上课时间，课堂归档管上课内容。** 你的注意力应该花在听讲上，记录这件事交给手机快门和自动归档。

## 三步用起来

1. **课前**：录一次课表（支持单双周、前八周/后八周、自定义周次），设置学期第一周
2. **课上**：PPT/板书各拍一张，收手机，认真听课
3. **课后**：照片传到电脑，拖进应用——按 EXIF 拍摄时间**自动归到课程和"第几堂课"**，缩放细看、荧光笔标重点、标星收藏

## 功能一览

- **自动归档**：拍摄时间 × 课表时间槽 × 单双周/周次范围，拍照即归位；错了一键「重新归课」批量重算，手动改过的永远不覆盖
- **课堂时间线**：每门课按「第几堂」编号回顾（第 1 堂到第 N 堂），记住你上次看到哪里
- **大屏复习**：滚轮缩放、拖动平移、连播；按周次/标星过滤，期末"把后半学期过一遍"一步到位
- **图片增强**：自动透视校正 + 去投影偏色 + 锐化，歪拍的投影照片变成端正清晰的"文档"
- **标注**：荧光笔（透字）、碳素笔、文字框，可撤销、可擦除；可导出带标注的图片分享
- **重点标星**：老师说"要考"的那页，标星后期末只看标星
- **隐私优先**：无账号、无服务器、无埋点。数据只存在你浏览器的私有沙箱里，zip 备份包随时导出迁移

## 数据安全（务必阅读）

照片和课表数据存储在**浏览器私有沙箱**（OPFS + IndexedDB）中，云端没有任何副本。请养成习惯：**每月在「备份」页导出一次完整备份包**，存到网盘或移动硬盘——清除浏览器站点数据或重装系统时，它是唯一的恢复手段。

## 技术栈

- Vite + React 18 + TypeScript + Tailwind CSS v4，react-router（HashRouter）
- 存储：OPFS（图片文件）+ IndexedDB（元数据，idb），schema v3
- 图像：OpenCV WASM（透视校正，懒加载）+ 纯 JS 自动增强管线
- PWA：vite-plugin-pwa，Service Worker 离线缓存
- 测试：43 个 lib 层单测（`npm test`），覆盖 EXIF 解析、课表匹配、单双周、透视校正、图像增强、标注几何、堂数推导

## 本地开发

```bash
npm install
npm run dev        # 启动开发服务器（--host，局域网可访问）
npm test           # 43 个 lib 层单测
npm run typecheck  # tsc --noEmit
npm run build      # 类型检查 + 构建 + 生成 Service Worker
npx gh-pages -d dist  # 发布到 GitHub Pages
```

浏览器要求：桌面端 Chrome / Edge（数据按浏览器隔离，固定用一个）；导入照片支持文件选择、整文件夹、拖拽三种方式。
